# Security Policy

## Supported versions

Spear Fia is pre-alpha. Only the latest commit on `main` of each repository receives
security fixes.

## Reporting a vulnerability

Please don't open a public issue. Either:

- use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  on the affected repository (Security tab ▸ Report a vulnerability), or
- email `security@spearfia.dev` (placeholder: not set up yet).

You can expect an acknowledgement within 7 days. Once a fix is ready we publish an
advisory and credit you unless you prefer otherwise.
